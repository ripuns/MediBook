# Admin Portal

This module contains the administrative dashboard and doctor-management screens for MediBook.

## Pages
- `dashboard/page.tsx` — overview summary cards for patients, doctors, appointments, and revenue.
- `doctors/page.tsx` — doctor directory with pagination-like summary and quick actions.
- `doctors/new/page.tsx` — form to add a new doctor profile.
- `doctors/[id]/page.tsx` — individual doctor details and schedule overview.

## Notes
This is the initial frontend shell for the admin experience, intended to be connected to backend APIs once the admin endpoints are ready.
